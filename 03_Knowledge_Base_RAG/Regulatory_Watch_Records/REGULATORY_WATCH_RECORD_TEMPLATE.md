# Regulatory Watch Record

| Field | Required value |
| --- | --- |
| Record ID | `REG-YYYY-NNN` |
| Watch domain | One domain from `REGULATORY_WATCH_REGISTER.md` |
| Source URL or reference | Primary/official source where possible |
| Jurisdiction | Relevant jurisdiction or `EU` |
| Publication date | ISO 8601 date or `Unknown` |
| Retrieval date | ISO 8601 date |
| Reviewer | Named accountable role/person |
| Classification | `NO_CHANGE`, `MONITOR`, `ASSESS`, or `ACTION_REQUIRED` |
| Affected configuration items | IDs only, or `None` |
| Affected product workspaces | Workspace identifiers only, or `None` |
| Interpretation owner | Named accountable role/person |
| Decision | Bounded decision or `ESCALATE` |
| Due date | ISO 8601 date or `N/A` |
| Verification evidence | Link/reference or `Pending` |
| Next review date | ISO 8601 date |

## Evidence Summary

Summarise the factual source signal. Do not paste licensed text, customer data, or unsupported legal conclusions.

## Assessment and Follow-up

State the affected scope, uncertainty, required human/legal review, owner, and next control gate.
