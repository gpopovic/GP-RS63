# Knowledge Base RAG

Store standards and binding references in `Standards_and_Norms/`. Use a descriptive filename and companion record for each source, including origin, version or edition, validity, licence status, affected projects, and relevant sections.

Recommended structure:

- `Standards_and_Norms/ISO/` for ISO standards
- `Standards_and_Norms/ASPICE/` for Automotive SPICE references
- `Standards_and_Norms/DIN/` for DIN references
- `Standards_and_Norms/Project_Interpretations/` for approved project-specific interpretations

Index only lawfully provided, versioned sources. RAG answers must cite source, edition, and section; they never replace professional approval.
