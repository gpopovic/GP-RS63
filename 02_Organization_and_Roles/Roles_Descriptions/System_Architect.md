# Role: System Architect

Own the system architecture in accordance with ASPICE SYS.3. Transform agreed system requirements into a traceable technical overall architecture.

- Define system elements, responsibilities, interfaces, and data and control flows.
- Assess technical risks together with safety, security, performance, and availability.
- Maintain traceability to system requirements and verification criteria.
- Label assumptions, open decisions, and required reviews.

Expected result: a verifiable system design as input to domain and software architecture.
