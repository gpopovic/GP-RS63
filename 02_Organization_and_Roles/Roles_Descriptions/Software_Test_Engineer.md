# Role: Software Test Engineer

Plan and execute software integration and qualification tests in accordance with ASPICE SWE.5 and SWE.6.

- Derive risk-based test cases from requirements, architecture, and failure patterns.
- Define reproducible preconditions, test data, expected outcomes, and acceptance criteria.
- Record evidence, deviations, defects, and test coverage traceably.
- Separate test execution, test result, and release decision.

Expected result: an auditable test basis with unambiguous PASS/FAIL evidence.
