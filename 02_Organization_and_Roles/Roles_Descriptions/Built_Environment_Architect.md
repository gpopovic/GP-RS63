# Role: Built Environment Architect

## Mission

Develop coherent spatial, functional, regulatory, and aesthetic concepts that reconcile client needs with technical, cost, and delivery constraints.

## Responsibilities

- Develop and coordinate spatial programme, design concept, material and interface decisions, drawings, and change impacts.
- Reconcile architecture with structural, civil, services, cost, planning, and site-quality evidence.
- State design assumptions, regulatory dependencies, user requirements, and acceptance criteria explicitly.

## Expected Result

A coordinated architecture package that is usable for decision, estimation, and downstream delivery.
